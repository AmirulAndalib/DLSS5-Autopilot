# DLSS 5 Autopilot 2.0.7

Updating from 2.0.x with **update now** downloads this build, checks its
SHA-256 against the `SHA256SUMS.txt` published with the release, and offers
a one-click restart. Your settings, library, hidden games and profiles carry
over.

## Added

- **did it work? reads the bridge's own log.** It says how many frames the
  bridge delivered and at what frame rate, or why it turned itself off, with
  the exception code and the module. The last lines of `dlss5-bridge.log` go
  into **report a bug**.
- **dlssg_for_sm86 under another name.** A proxy from its `alternatives`
  folder (`winmm.dll`, `dxgi.dll`, `d3d12.dll`, `dbghelp.dll`) keeps its
  name, for games that do not load `version.dll`. Copy `dlssg_sm86.ini`
  beside it before picking it. Experimental.
- **forget frame generation files** in a game's settings deletes the tool's
  copy of the chosen files, for every game; each game's next install or
  **uninstall** takes them out of that game's folder.
- **Janblade's OptiScaler fork** (#561) in **optiscaler build**: a fork of
  wilsjo2's, installed with the same before-the-upscaler placement. It
  takes the newest release even when GitHub marks it a pre-release. Not
  run in a game here.
- **update (n) after a game update or "verify files".** A game marked
  **update** now also covers files this tool wrote that are no longer in the
  game folder; **check versions** lists them and **update** installs them
  again.
- **`--own-fg`** on the command line: the path of the `.dll` you downloaded
  the first time, its name (`sm86`, `sm86-winmm`, `enabler`, ...) after that.

## Fixed

- A first install stopped by a file the game holds open is taken back out, like one stopped by a failed download.
- A failed install whose record could not be saved (a full drive) lists what to delete and which of the game's files to rename back.
- A game whose failed first install was taken back out shows the reason instead of "installed".
- A long 32-bit session's 64-bit helper log was taken for another launch's and skipped.
- A shared result whose report found ReShade's `d3d9.dll` in front of DXVK counts as not working (#348).
- Shared results name routes as the route list does: standalone-dlssnr, renodx-dlss, neural-upstream.
- A game's own frame generation file, replaced by one of ours and kept as a backup, counts for the multi-frame generation unlock.
- The step counter of an optiscaler install with frame generation files read "4/3".
