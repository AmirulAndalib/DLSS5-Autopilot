# DLSS 5 Autopilot 1.9.0

The tool stops guessing about what happened in your game: it can start it,
read what the running process actually loaded, and try the next route by
itself when nothing of ours got in.

Updating from 1.8.x with [ update now ] downloads the new build, checks its
SHA-256 against the `SHA256SUMS.txt` published with the release, and offers
a one-click restart.

## What changes for you

- **"install and try it for me".** One press: it installs the route, starts
  the game, waits for it to settle and reads which DLLs the running process
  loaded. Our files in the game means the chain is in and you can play; the
  game loading Windows' own dxgi.dll instead means that route cannot work in
  that folder however often it is installed - so the next route is installed
  and you are asked to start the game again. Three routes, then it stops and
  says what it found. It reads the process and writes nothing into it.
  - It never starts a game with anti-cheat in the folder, and never a
    launcher executable - it says so and waits for you to start the game
    yourself, which changes nothing else about the pass. A game with
    anti-cheat asks the same question INSTALL asks before anything is
    written at all.
  - The screen before it runs lists every step, in those words, including
    that it may install a second route without asking again.
  - Experimental: the pass is covered by tests end to end, but the only
    machine it has been run on is one RTX 4060 Ti at 1080p. It stops after
    three routes and 'stop' ends it after the route it is on.
- **A swap says what it replaced.** `nvngx_dlss 310.2.1 -> 310.9.1
  (NVIDIA SDK)` in the log - the version stamped in the file that was
  there, then the build that went in - instead of only the new one. Same
  for ray reconstruction and frame generation. Replacing a build with
  itself prints one version, not an arrow.
- **An install that crashed is no longer read as a folder nobody installed
  into.** A download that dies on a DNS lookup, a 500 from the publisher or
  a refused file leaves an empty folder, and the tool used to answer "run
  the game once and check again" (#213) or blame antivirus for a file that
  was never written (#61). The traceback it already prints in every report
  is now read: what stopped the install is said, and what to do about it.
- **The report says whether the standalone route's two shaders are there.**
  `DLSS5_AIO_Feed.fx` and `vort_Motion.fx` decide whether that route can do
  anything, the diagnosis asked people to go and check them by hand, and
  the report they were reading had no line about either (#212). A shader the
  install wrote and something has since removed is now named as a fact.
- **The install record carries the build of the tool that wrote it**, so
  from this release on a folder set up by an older build says so under the
  diagnosis (#215). Folders set up before this release carry no build
  number and are not flagged.
- **The window's settings could not scroll at 100% scaling.** The last
  setting sat below the bottom edge with no scrollbar: the scroller
  measured the height it had asked for instead of the height it was given,
  and the page did not subtract the new button row from what the settings
  were handed. Both are fixed.

## Already there, in case it went past you

- **Keeping a game's DLSS up to date.** Super resolution
  (`nvngx_dlss.dll`), frame generation (`nvngx_dlssg.dll`) and, for a game
  that ships one, ray reconstruction (`nvngx_dlssd.dll`) can be replaced
  with builds fetched from NVIDIA's own repository - the game's file is
  backed up and comes back on uninstall. **check versions** then says which
  of your games has a part with a newer build.
- **Films, YouTube, a webcam, or whatever is on the screen** go through the
  same neural pass, on the **video and youtube** page.
- **What will happen?** prints every file INSTALL would write, back up and
  remove, and writes none of them.

## Under it

- `core/autopilot.py`: the pass above, as a plain state machine - install,
  start, wait, read the module list, decide - with everything that touches
  the world handed in, so the whole loop is tested without a game.
- The replay that answers "what would the tool say about this report" now
  rebuilds a Remix install (the `.trex` runtime, its flavour and `rtx.conf`)
  and reads the Remix log, so the rules for that route are covered by the
  reports the corpus holds instead of by nothing at all.
